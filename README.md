# A Global Pomodoro Timer

## Description 
A simple web application that allows users to utilize the Pomodoro Technique to study together. 

You can spin up the webpage here: [https://pomotimer-server.onrender.com/](https://pomotimer-server.onrender.com/)

Note that the website will take about 1-2 minutes to load because it will turn off based on inactivity

## Installation
To run the application locally on your machine, clone the repository and run:

```
npm install
```

And then start the server with

```
npm start
```

If you end up with a nodemon error, make sure it is installed globally via

```
npm install -g nodemon
```
